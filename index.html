Reinas

Aprende las técnicas, mejora tus tiempos y resuelve cada puzzle sin adivinar.

¿Cómo se juega?
  • Pon exactamente una reina en cada fila, cada columna y cada región de color.
  • Dos reinas no pueden tocarse, ni siquiera en diagonal.
  • Toca una casilla una vez para marcar ×, otra vez para poner una reina. Arrastra para marcar varias ×.
